Instance Mask Picker

1. Click the color blocks you want in the mask

Each instance is a flat color held for the whole clip, so you can click it on any frame. Click as many color blocks as you want -- they all get combined into one mask. Check invert selection to mask everything except the colors you picked.

2. Check the produced mask

Load an existing mask .npy

Visualize a mask that wasn't generated here -- e.g. output from batch_generate_masks.py, or a previously downloaded one. It must be a boolean/0-1 array shaped (num_frames, H, W) matching the currently loaded video (a single-frame (1, H, W) array is also accepted and held for every frame).
