# vlm_v0.0

`franka_review_vlm_v0.0.csv` is the first version of the review list of the Franka dataset
franka_towel_n750_seeds1234. It was made on 2026-10-12 (PT).
It has 350 reviewed videos: approved 99, weak 110, rejected 141.
It is a byte copy of `lists/review.csv` in the share folder franka_towel_n750_seeds1234_videos.
